# DWP — 疑似DocuWorks（デスク・書き込み・モジュールグリッド連携）

PDFやスキャン画像を **書類（束）** としてデスクに並べ、**ばらす・結合・回転・書き込み** をして
PDFに **書き出す** ための単一HTMLアプリです。（DWP = DocWorks Pseudo）

## 使い方（2通り）
- **公開URL**：ブラウザで開くだけ（ブックマーク推奨）
- **ローカル**：`index.html` をダブルクリック（`lib` フォルダを必ず一緒に。ネット接続不要）

## できること
| 分類 | 機能 |
|---|---|
| デスク | 1ファイル=1書類で並ぶ／重ねてドロップで**結合**／**ばらす**（1ページずつに分解）／名前変更／**1書類=1PDF保存**／**📁 フォルダ**（書類をドラッグで放り込んで整理・レ点でまとめて格納・ダブルクリックで開く・開いたまま取り込むとその中へ）／**Ctrl+Vでスクショ貼り付け** |
| 中身（ページ） | 並べ替え・回転・削除・**コピー**（元の直後に複製）／選択ページの**抜き出し**／選択だけ書き出し |
| 書き込み | ペン・マーカー（直線帯）・付箋・直線・矢印・囲み・文字・ハンコ・消しゴム・**移動**／色・太さ・濃さ自由設定／**図面の線・文字への吸着**／ホイール拡大＋スペースドラッグ移動／右クリックで戻す |
| 表示 | クリックで右に大きくプレビュー（**前後ページ送り・マウス位置基準の拡大縮小・ドラッグ移動**）→さらにクリックで**全画面ビューア**（ホイール拡大・**ページ送り**）／**別ウィンドウ表示** |
| 線レイヤー | **スキャン図面（線データのないPDF・画像）から通り芯・外形の線を自動検出**し、赤の半透明で重ね表示。**📏 線:ON/OFF**で切替。書き込みやPDF保存には影響しない補助表示 |
| 変換 | **🔄 変換**＝PDFを**JPEG／PNG**（解像度150〜600dpiを選択）や**DXF**（CADで読める線データ・試験機能）にして保存。1ページ＝1ファイル。途中で**中止**できます |
| 連携 | **モジュールグリッドへ送る**（書類ごと／選択ページだけ）→ 線を引いて「**DWPへ戻す**」でデスクに帰ってくる |
| 保存 | **自動保存**（ブラウザ内）。次に開くと前回のデスクを復元／**🛟 バックアップ**＝デスク一式を1ファイル（.dwpbk）に保存→**画面へドロップで復元**（別PCへの引っ越しにも） |

## 🔄 変換について（PDF → JPEG / PNG / DXF）

ヘッダの **🔄 変換** から。デスクでは選んだ書類、開いた書類の中ではページが対象になります。

### 画像（JPEG / PNG）
解像度は **150〜600dpi** から選べます。線を大事にするなら **PNG**（JPEGは圧縮で細線がにじみます）。
書き込み（ペン・付箋・ハンコ）を一緒に描くかどうかも選べます。
大きな図面は1ページに時間がかかります。**ボタンが「⏹ 中止」に変わる**ので、途中でやめられます。
複数ページのときは、ブラウザが「複数のファイルのダウンロード」を尋ねることがあります。**「許可」**を選んでください。

### DXF（試験機能）
**PDFの見た目の線をDXFに写す**機能です。**元のCADデータの復元ではありません。**

- 対象は **線データを持つPDF**（CADから出力したPDF）。**スキャン図面からは線を取り出せません**
- 出るのは **線（LINE・LWPOLYLINE）と文字（TEXT）だけ**。線幅・線種・色・レイヤーは失われ、1つのレイヤーにまとまります
- 容量を抑えるため、**つながった線は1本のポリライン（LWPOLYLINE）にまとめ**、線のZ座標は書きません（形・位置は変わりません。Jw_cad・NETEAGLE で開けることを確認済み）。CADでは、まとめた線は1本として選択されます
- **PDFで切り抜かれて見えていない部分や、用紙の外にはみ出した部分は切り詰めます**。切り抜きの境界の上に乗った線（図面枠など）は残します
- PDFの座標の倍率（UserUnit）が1でないPDFも、その倍率を寸法に反映します
- 次のものは正しく扱えません：**白く塗って上から隠した線**、**透明にした線**、**切り抜きの外にある文字**（文字は用紙の外のものだけ除きます）
- **実寸(mm)はPDFだけでは決まりません。** 次の3つから選びます
  - **縮尺を入力**（1/100 など）… 印刷時に「用紙に合わせる」で縮小されたPDFでは合いません
  - **2点で測って合わせる** … 図面上で実寸の分かる2点をクリックして長さを入力（いちばん確実）
  - **用紙の原寸（1/1）**
- **文字コードは Shift-JIS が既定**です（Jw_cad・NETEAGLE はDXFをShift-JISとして読むため。UTF-8で出すと文字化けします）。
  他のCADで開けないときは **UTF-8** や **\U+変換** でも出せます。Shift-JISに無い文字は `?` になり、その文字と個数がレポートに出ます
- 変換後に「線◯本・文字◯個／切り詰めた線・曲線・画像◯件」という**レポート**が出ます
- 動作の確かめ方（開発用）：`tools/dxf_selftest.js` を読み込んで `await dxfSelfTest()`（切り抜き・回転・UserUnit などの自己試験18件）
- **CADで開いたら、必ず1か所は寸法を測って確かめてください**

### 📐 Jw_cadの図面（.jww）をDXFにしたいとき
**このアプリではなく Jw_cad 本体を使ってください。** Jw_cad自身の変換なので最も確実です
（DWPのPDF変換のような欠落がありません）。

- 1ファイルだけ：Jw_cadで開いて **ファイル → DXF形式で保存**
- まとめて何枚も：**ファイル → ファイル操作 → ファイル一括変換**

※ ブラウザのアプリからパソコンのソフト（Jw_cad）を起動することはできないため、DWPには組み込んでいません。

## 📦 データはどこに保存される？
取り込んだPDF・書き込み・デスクの状態は、**すべて使っている人のパソコンのブラウザ内**（IndexedDB）に保存されます。
- **ネットには一切送信されません**（このアプリは通信をしません）
- 他の人のデスクは見えません（PCごと・ブラウザごとに別々）
- ブラウザの閲覧データ削除や、**ディスク容量がいっぱいのとき**に消えることがあります。**「🛟 バックアップ保存」を習慣にしてください**（アプリからも保護を要求していますが、バックアップが確実です）
